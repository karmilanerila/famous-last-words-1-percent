One line (127 characters) — the funniest possible last words a phone would say when its battery hits 1 percent. Dramatic, specific, self-aware: 47 tabs open, one unsent text, not a single photo backed up — and a goodbye to the charger.

The line: "So this is how it ends — 47 tabs open, one unsent text, and not a single photo backed up. Tell the charger I loved it. Goodbye."

## Run it

```sh
python3 main.py
```

It writes the line to /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt), mode 0644, and refuses to write anything outside the 1–199 character gate.
